# Notes for Review (Version 1.0 (6))

Paste this into **App Store Connect → App Review Information → Notes**.

WCS Platform is an education app supporting:
- course discovery
- course detail and enrollment
- lesson playback
- quizzes and assignments
- discussion
- profile and membership context

Reviewer path:
1. Launch app
2. Discover tab: browse featured items
3. Programs tab: open a course and module
4. Discussion tab: open threads
5. Profile tab: membership and account context

Important:
- Admin AI Course Studio is restricted for admin workflows and is not required for standard learner validation.
- Individual digital subscriptions use Apple In-App Purchase.
- Organization/enterprise access can be entitlement-based (B2B contract), not a consumer bypass flow.
- No special hardware is required.

If reviewer credentials are needed for your current build, provide them in the secure App Review credential fields.
